# 🖼️ Visualia – Image Gallery

A modern and responsive **Image Gallery** built using HTML5, CSS3, and JavaScript. The project displays multiple images in a responsive grid and provides an interactive lightbox preview when an image is selected.

## 📌 About the Project

Visualia is a responsive image gallery designed to practice **CSS Grid, responsive web design, JavaScript events, DOM manipulation, and basic UI interactions**.

Users can browse the gallery, click on any image to view it in a larger preview, and navigate between images using the previous and next buttons.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* CSS Grid
* Unsplash Images

## ✨ Features

* Responsive image grid

## ⚙️ How It Was Built

### HTML

HTML5 is used to create:

* Header
* Gallery section
* Image cards
* Lightbox preview
* Navigation buttons
* Close button

### CSS

CSS3 is used for:

* CSS Grid layout
* Responsive design
* Image hover effects
* Modern dark UI
* Glassmorphism effects
* Animations
* Mobile and tablet layouts

### JavaScript

JavaScript is used to:

* Detect image clicks
* Open the lightbox
* Display the selected image
* Navigate to previous and next images
* Close the preview
* Update the image counter
* Handle keyboard controls

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Click any image to open the large preview.
5. Use the navigation buttons or keyboard arrows to browse images.

## ⌨️ Keyboard Controls

| Key   | Action         |
| ----- | -------------- |
| `←`   | Previous Image |
| `→`   | Next Image     |
| `Esc` | Close Preview  |

## 🌐 Image Source

The project uses images from **Unsplash** through image URLs.

An internet connection is required for the external images to load.
